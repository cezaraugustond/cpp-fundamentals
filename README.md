# Fundamentos em C++

Este repositório contém meus estudos, anotações, exercícios e implementações práticas desenvolvidas durante o curso de Lógica de Programação em C++, realizado no site [Code For Giants](https://www.codeforgiants.com/).

O objetivo deste repositório é documentar minha evolução na linguagem C++, desde os conceitos mais básicos até assuntos fundamentais relacionados à memória, ponteiros, arrays, structs e organização de código.

Durante o curso, foram abordados conceitos essenciais de programação, utilizando o compilador MinGW e o editor Visual Studio Code como ambiente de desenvolvimento.

---

### [1. Básicos da Linguagem](./1-basics/)

* Comentários

* Conversão de tipos (casting)

### [2. Estruturas Condicionais](./2-conditionals/)

* Operadores relacionais

* `if`, `else if` e `else`

* Operador ternário
* `char` e tabela ASCII

### [3. Estruturas de Repetição](./3-loops/)

* `while`
* `do while`
* `for`
* Controle de fluxo (`break`)

### [4. Funções e Organização de Código](./4-functions/)

* Criação de funções
* Parâmetros por valor e referência
* Escopo de variáveis
* Variáveis globais e estáticas
* Bibliotecas
* Tratamento de erros
* `namespace`

### [5. Arrays e Strings](./5-arrays-and-strings/)

* Vetores

* Strings em C++
* Arrays multidimensionais

### [6. Memória e Ponteiros](./6-memory-and-pointers/)

* Funcionamento básico da memória
* Bits e bytes
* Endereços de memória
* Ponteiros
* Operador de referência (`&`)
* Operador de desreferência (`*`)

* Implementação básica de uma string personalizada

### [7. Structs](./7-structs/)

* Estruturas (`struct`)
* Métodos em structs
* Construtores

* Organização de dados compostos
